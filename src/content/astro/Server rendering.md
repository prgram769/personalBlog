---

- **Renderizado bajo demanda (on demand rendering/ SSR):** Permite pasar de una web puramente estatica a generar paginas dinamicas en el servidor segun la peticion del usuario.
- **[[Island Architecture |Server islands]]:** Permite incrustrar bloques dinamicos que se renderizan bajo demanda en el servidor dentro de una pagina estatica pre-renderizada.
- **Actions y sessions:** Proporciona utilidades nativas (`astro:actions`) para gestionar la gestion de formularios y mutaciones de datos con seguridad de tipos asi como el manejo de sesiones de usuarios (`sessions`).
