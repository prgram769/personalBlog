- **Estructura .astro:** Se componen de dos secciones:
	1. **Script de frontmatter (delimitado por ---):** Se ejecuta en tiempo de compilacion o servidor para hacer importaciones, consultar fuentes de datos o preparar variables.
	2. **Plantilla de marcado:** Define el HTML estructurado mediante expresiones dinamicas y directivas de plantillas.
- **Ecosistema UI:** Facilita la inclusion de CSS integrado, gestion de fuentes, resaltado de sintaxis, scripts del cliente y optimizacion de imagenes a traves de *astro:assets* o componentes de imagen personalizados.
