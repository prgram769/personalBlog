Los principales fundamentos de astro son los siguientes:

- **[[Island Architecture]]: Es uno de los pilares principales de astro para estructurar paginas web y optimizar la carga e interactividad en el cliente.
- **[[Astro components and template syntax]]**: La interfaz de usuario se construye utilizando componentes nativos de astro y su sintaxis de plantillas.
- **[[Routes and structure]]**: La navegación y el enrutamiento del sitio se organizan a traves de paginas y layouts.
- **[[Frameworks front end compatibility]]**: Permite integrar de forma directa componentes de multiples librerias y frameworks como React, Vue, Svelte, Preact, SolidJS y AlpineJS.
- **[[Content collections]]**: Incluye herramientas nativas para trabajar con Markdown, MDX y colecciones de contenido con seguridad de tipos.
- **[[Server rendering]]**: Ofrece capacidades de renderizado bajo demanda, rutas de API/endpoints, middleware y server islands.
